## ✨ Key Features

- 📁 **Categorized Portfolio Gallery**:
  - 50+ high-resolution project images categorized into 5 core services:
    - ⚡ **Electrical & Wiring**
    - 📶 **Network & Data**
    - 📹 **CCTV & Security**
    - 🔋 **Backup Power (Solar & UPS)**
    - 🛡️ **Earthing & Compliance**
  - **Category Filter Tabs** with real-time project count badges.
  - **View Mode Switcher**: Toggle between *Filtered Grid View* and *Grouped Category View*.
  - **Instant Search**: Filter projects dynamically by name or filename.
  - **Lightbox Modal**: Click any project photo for full-screen inspection.
- 📱 **Direct Contact Action Buttons**:
  - One-click phone calling & WhatsApp messaging.
- 🎨 **Modern Design & Micro-Animations**:
  - Built with custom CSS tokens, dark mode aesthetics, glassmorphism cards, and smooth hover transitions.
- 🔒 **Read-Only Client Security**:
  - Clean public view for clients while keeping backend configuration safe.

## 🚀 Local Development Setup

To run the project locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BYM1127/IMELA-PROJECTS.git
   cd IMELA-PROJECTS
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```
